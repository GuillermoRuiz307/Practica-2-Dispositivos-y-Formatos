# Practica-2-Dispositivos-y-Formatos

Entrega proyecto de Unreal Engine para la Práctica 2 de Dispositivos y Formatos, por Guillermo Ruiz Ruiz



CONTROLES:

* W-A-S-D (Fuera de la maquina): Moverse con el personaje
* Flecha Izquierda - Flecha Derecha (En la maquina): Usar los flippers
* Ñ (En la maquina): Respawnear la bola
